# Power Vision Engineering - Business Management System

## Project Overview
PVE-BMS is a Business Management System developed for Power Vision Engineering.

## Technology Stack
- Frontend: Angular, TypeScript, HTML, CSS
- Backend: Java, Spring Boot
- Database: PostgreSQL
- API: REST API
- Version Control: Git and GitHub

## Current Development Scope
1. Product Management
2. Category Management

## Implemented Features

### Category Management
- View categories
- Create categories
- Update categories
- Delete categories
- Activate and deactivate categories
- Search and filter categories

### Product Management
- View products
- Create products
- Update products
- Delete products
- Search products
- Assign products to categories
- Manage SKU, barcode and prices

## Project Structure
- pve-bms-frontend: Angular application
- pve-bms-backend: Spring Boot application
